DataStream Transformation 转换算子
    1). 基础三剑客算子  
        【对数据流中每条数据处理，都需要接收参数：函数接口类型参数】
        map ->   1 对 1
        flatMap ->  1 对  N (= 0, 1, >1)
        filter  ->  1 对 0 或 1
    2). 分组算子
        keyBy -> 将数据流中数据按照指定的Key进行分组，得到数据流为分组流KeyedStream
        【分组后流数据，需要调用sum类型聚合算子或window类型窗口算子对数据处理】
    3). 规约算子（聚合算子）
        reduce ->对分组后数据流进行聚合操作算子，对每个组中数据进行聚合操作
                reduce(tmp, item)
    4). 最大最小值算子
        max/maxBy 或 min/minBy ->  对分组流中每个组中数据获取最大值或者最小值
            max: 只关心指定字段的最大值
            maxBy：不仅关心指定字段的值还关心相关字段的值，推荐使用
    【filter算子和keyBy算子，书写代码时，使用lambda表达式书写，实现逻辑简单，代码简洁】
