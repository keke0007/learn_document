## 大数据概述

### 什么是大数据

+ 术语

  + 数据：一切能够被计算机存储的东西都是数据

  + 数据的体量

     ```shell
     常见数据存储单位：
     1Byte = 8bit    1K(千)= 1024Byte  1MB（兆)=1024K  1G(吉) = 1024M
     1T(太)=1024G    
     #-------------------------------------------------------------
     1P(拍)=1024T     1E(艾)=1024P     1Z(泽)=1024E
     1Y (尧)=1024Z    1B(布)=1024Y     1N(诺)=1024B    1D(刀)=1024N
     
     ```

    大数据的数据体量一般是：T、P , E

+ 定义

  + 使用常规的数据处理手段无法处理目前的数据，需要使用新的处理技术，这些技术就是大数据

  + 大数据主要解决**海量数据的存储**问题和**海量数据的计算**问题

    ```shell
    #用于数据存储的框架
     HDFS、HBase、Redis、Kudu、Doris ，Kafka
    #用于数据计算的框架
     MapReduce、Spark、Flink，[Storm]
    #其他辅助框架
     Zookeeper、Sqoop,Flume、Kettle，Azkaban、Oozie
    ```

### 分布式和集群

+ 分布式

  将原来的一个系统进行拆分，拆分到不同的主机上，每台主机负责一部分模块。

  分布式强调的是拆分，多个人分别做不同的事情

  + 单机模式，一个餐厅：  一个人，既要买菜，又要洗菜/切菜，又要炒菜
  + 分布式模式，一个餐厅：三个人，一个人买菜，一个人洗菜/切菜，一个人炒菜

+ 集群

  将同一个任务分散到不同的主机上运行，集群强调多个人干相同的事情

  + 分布式+ 集群

     一个餐厅：9个人

    ​       三个人买菜           ---- >集群

    ​       三个人洗菜/切菜  ---- >集群

    ​       三个人炒菜           ---- >集群

## Hadoop

### Hadoop概念

+ Hadoop是一个软件，这个软件包含三个模块
  + HDFS: Hadoop分布式文件系统
  + MapReduce:分布式计算系统
  + Yarn:分布式资源调度系统

  ![image-20220122222108151](image\image-20220122222108151.png)
  
+ 后期很多的大数据框架都基于Hadoop

+ 有时，我们又把Hadoop称作一个生态圈

   ![image-20220122210120317](image\image-20220122210120317.png)

### Hadoop的发展史

+ Hadoop的发展是由谷歌的两篇论文（GFS，MapReduce）发起的
+ Hadoop现在由Apache组织来维护

### Hadoop的版本

#### 数字版本

+ 1.x 最老的版本，已淘汰
+ 2.x 在1.x之上加入了Yarn，目前使用率最高
+ 3.x 最新，加入了很多新特性（课程使用的Hadoop是：3.1.4）

#### 免费版

+ apache版
  + 优点：版本丰富
  + 缺点：版本更新过快，版本之间的兼容性稍差

#### 发行版-收费

发行版就是在Apache的原生的Hadoop之上进行了Bug的修复和优化

+ HortonWorks : 已经被cloudera公司收购， ----》HDP
+ cloudera ：目前全球最大的大数据公司       ----》CDH
  + 优点：比较问题，不容易出问题
  + 缺点：版本更新慢
